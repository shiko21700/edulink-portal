#  EduLink Portal

Мектептегі мұғалім, оқушы және ата-ана арасындағы күнделікті байланысты жеңілдетуге арналған веб-платформа.

Мұнда мұғалімдер қатысу журналын белгілеп, хабарландыру тарата алады, ал ата-аналар баласының сабағын бақылап, мұғаліммен тікелей сөйлесе алады.

---

## Негізгі мүмкіндіктері

- **Рөлдерді ауыстыру:** Мұғалім, Ата-ана және Оқушы кабинеті.
- **Жұмыс уақыты бар чат:** Мұғалімдерге кешкісін маза бермеу үшін хабарлама жіберуді 08:00–18:00 аралығымен шектеу логикасы қосылған.
- **Қатысу журналы:** Календарь арқылы қай күні кімнің сабақта болғанын/болмағанын белгілеу.
- **Мектеп хабарландырулары:** Маңызды жаңалықтарды баршаға бір жерден жеткізу.

---

##  Технологиялар

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Hosting:** Vercel

##  Компьютерде іске қосу

```bash
# 1. Репозиторийді көшіріп алу
git clone [https://github.com/shiko21700/edulink-portal.git](https://github.com/shiko21700/edulink-portal.git)

# 2. Папкаға өту
cd edulink-portal

# 3. Пакеттерді орнату
npm install
